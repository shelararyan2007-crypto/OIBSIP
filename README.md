# ATM Interface

A console-based ATM Interface developed in Java as part of the Oasis Infobyte Java Development Internship.

The application simulates basic ATM operations such as user authentication, balance checking, deposits, withdrawals, fund transfers, and transaction history.

---

## Features

- Secure User ID and PIN authentication
- Maximum 3 login attempts
- Account balance checking
- Cash withdrawal
- Cash deposit
- Fund transfer between accounts
- Transaction history
- Insufficient balance validation
- Invalid input handling
- Multiple sample bank accounts
- Transaction date and time tracking
- Clean console-based interface

---

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections
- Java Time API
