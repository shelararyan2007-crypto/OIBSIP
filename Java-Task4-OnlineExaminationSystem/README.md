# Online Examination System

A desktop-based Online Examination System developed in Java using Java Swing and Object-Oriented Programming concepts.

This project was developed as part of the **Oasis Infobyte Java Development Internship – Task 4**.

## Features

- Student login authentication
- User ID and password validation
- Student profile management
- Profile input validation
- Multiple-choice examination
- One question displayed at a time
- Next and Previous question navigation
- Answer persistence while navigating
- Countdown examination timer
- Automatic submission when time expires
- Manual exam submission
- Submission confirmation
- Automatic score calculation
- Correct and incorrect answer count
- Percentage calculation
- Pass/Fail status
- Logout functionality
- Exit confirmation

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- VS Code
- JDK 21

## OOP Concepts Used

The project demonstrates several Object-Oriented Programming concepts:

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Data abstraction
- Object interaction
