# Number Guessing Game

A Java Swing-based Number Guessing Game developed as part of the Oasis Infobyte Java Development Internship – Task 2.

The game generates a random number within a selected difficulty range and allows the player to guess the number within a limited number of attempts.

## Features

- Random number generation
- Three difficulty levels
- Easy, Medium and Hard modes
- User guess input
- Too High / Too Low hints
- Correct answer detection
- Attempt counter
- Maximum attempt limit
- You Lost message
- Correct number revealed after losing
- Play Again functionality
- Round tracking
- Score tracking
- Input validation
- Range validation
- Keyboard Enter support

## Difficulty Levels

| Difficulty | Number Range | Maximum Attempts |
|------------|--------------|------------------|
| Easy | 1 – 50 | 10 |
| Medium | 1 – 100 | 7 |
| Hard | 1 – 200 | 5 |

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- Java Random
- VS Code
- JDK 21
